关于 iOS / macOS 的安装包

Apple 不提供任何公开的 IPA 下载接口。App Store 的分发协议要求安装包只能由 App Store 客户端在用户本人 Apple ID 授权下解密安装，所以网页这边默认给 iOS 的结果是 App Store 页面链接，而不是 .ipa 文件。

要在这个页面里直接拿到包，就走本机 ipatool 这条路：

brew install ipatool   # 装好之后刷新页面，顶部会多出 App Store 状态条

点顶部的「连接账号」，用你自己的 Apple ID 登录（含两步验证），之后 iOS 与 Mac App Store 的卡片上会出现「下载 IPA / PKG」。可以选设备（iPhone / iPad / Mac / Apple TV / Watch / Vision Pro），也能挑历史版本。凭证由 ipatool 存在本机 keychain，密码只在本机内存里过一次。

如果你手上已经有一个第三方分发页（企业签名自建 OTA、内测分发平台、自己的 itms-services 链接），点顶部「提取 IPA」把链接粘进去，就能直接拿到里面的 .ipa 地址、包名和版本——这条路不需要 Apple ID，因为它只是解析页面里已经公开的 OTA 清单。

几点得先说清楚：

  • 包是加密的：下到的 IPA 仍是 FairPlay 加密、并绑在你的账号上，只能装到你本人登录同一 Apple ID 的设备（配合 Apple Configurator / iMazing 之类），不能当成破解包分发。
  • 只能下免费或你已购买的应用：免费应用会自动领许可；付费的必须先在 App Store 里买过。
  • 部分应用不开放下载：开发者可以选择不提供给第三方客户端，这类会直接报错。

第三方「IPA 库」站点分发的是破解 / 重签包，属于侵权且常被注入恶意代码，本工具不做聚合。
